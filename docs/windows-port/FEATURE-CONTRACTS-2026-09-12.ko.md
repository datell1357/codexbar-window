## 구현 작업자의 완료 기록

각 source obligation의 ID·원본 blob/line에 Windows symbol·설정/default/error 대응·fixture 및 검증 로그를 연결한다. 행의 등록은 구현 완료가 아니다. 한 기능군의 모든 필수 source 계약과 플랫폼 결정이 종결돼야 그 기능군을 완료 처리한다. 동적/암묵적 동작이 추가로 발견되면 기존 ID를 유지하고 하위 항목을 추가한다. 파일 책임 분류 100%를 의미 검토나 제품 완성률로 바꾸지 않는다.
