# QA057 — 손상된 세션 기록 자동 복구

진행 중. Windows 저장 코드에서 JSON 디코딩 오류만 복구 대상으로 분류한다. 원래 바이트를 인접한 새 백업에 덮어쓰기 없이 보존한 뒤에만 새 기록 저장을 허용한다. 백업 실패 또는 일반 파일 I/O 오류는 전파하며 원래 기록을 그대로 둔다. 실제 파일 삭제·이동·앱 실행 없이 소스만 편집한다. 056의 임시 저장 실패 테스트는 구현 검토 후 백업 보존 및 복구 계약으로 갱신해야 한다. 전체 동등성 완료 아님.

root 정적 검토에서 Data.write의 atomic + withoutOverwriting 동시 옵션 문제를 발견해 백업은 withoutOverwriting만 사용하도록 수정했다. 백업을 원자적이라고 주장하지 않는다. 백업 쓰기가 성공해야 원래 기록에 atomic 저장을 진행하며, 실패 시 원본 유지 계약이다. 독립 검토와 복구 성공/백업 바이트 테스트 소스 갱신을 진행한다.

독립 정적 검토에서 복구 구현과 성공 fixture의 일치를 확인했다. 백업 실패/일반 I/O 실패의 전용 fixture는 아직 없으며 실행 검증도 없다. 049와 함께 통합 검토 후 부분 구현 단계로 커밋할 예정이고 전체 기능 완료로 처리하지 않는다.
