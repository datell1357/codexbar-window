# QA085-087 — 개인정보 및 선택적 사용량 제어

개인정보 메뉴 초안을 Root가 정적으로 확인했다. 기존 안전한 제목 및 cache 재표시 callback을 사용한다. 선택적 사용량 메뉴는 별도 callback으로 연결 중이다. 켜기: 진행 중 조회와 겹쳐도 후속 조회가 누락되지 않아야 한다. 끄기: 즉시 숨기고 추가 조회하지 않는다. 이전 optional=false 결과가 켜기 이후 새 표시를 덮지 않도록 해야 한다. 종료 후 후속 조회 금지, 공급자 순서/오류 보존, 표시 및 개인정보 토글의 추가 조회 없음이 독립 정적 검토 기준이다. 아직 미승인, 실행 검증 없음.

Root 초안 검토: optional=true 조회 중 끄기를 수행하면 기존 equality gate가 기본 사용량과 오류까지 버리는 문제 발견. false 조회 이후 켜기만 후속 조회로 대체하고, true 조회 이후 끄기는 최신 표시 설정으로 기본 데이터/오류를 게시하도록 수정 요청했다. 088 독립 검토 진행 중, 미승인.

최종 088: 방향별 결과 처리, 직렬 후속 조회, 메뉴 callback 및 종료 queue 정리를 코드 비교로 확인했다. 변경 범위 추가 필수 차단 사항 없음. 부분 단계 정적 승인. diff --check 통과, Actions 비활성 확인. 빌드·컴파일러·테스트·Windows 실행 검증 없음. 전체 기능 동등성은 미완료.
