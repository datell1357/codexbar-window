# QA099–100 — 시작 연결 재시도 (수정 중)

고정 원본 `928166f899471bbdcb72210641cdec91324d0154`의 UsageStore 시작 재시도 계약을 WindowsUsageRuntime에 연결하는 중이다. 15/45/120/300초 제한 재시도 및 URL 오류 분류 초안을 작성했다.

독립 정적 검토 100은 REQUEST CHANGES다. 완료된 refreshTask를 반복 await하는 방식의 소유권/대기 문제, optional 연속 갱신에서 실패 플래그가 지워지는 문제, 원본에서 재시도를 시작하지 않는 plugin 오류를 포함한 문제를 수정한다. 불필요한 attempt 저장 필드도 제거한다. 수정 후 독립 재검토 전 커밋하지 않는다.

빌드·테스트·컴파일·실행 검증은 하지 않았다. 전체 기능 동등성 승인이 아니다.

추가 통합 검토: Task.yield 반복 대기도 승인하지 않았다. 실제 refresh 소유자의 완료 통지로 대기자를 깨우고, 취소·종료 이후 retry 예약이 다시 생성되지 않도록 수정 후 독립 검토한다.

최종 수정: 완료 통지는 optional 추가 갱신까지 끝난 후 전달하며 깨어난 대기자는 슬롯이 다시 점유됐으면 continuation으로 다시 기다린다. 취소·종료 시 재예약하지 않는다. plugin 제외와 pass 단위 실패 상태를 유지한다. 독립 검토 100은 수정된 범위를 정적 승인했다. 15/45/120/300초 네 번의 재시도와 원본 오류 분류를 비교했다. 실제 Windows 실행은 미검증이다.
