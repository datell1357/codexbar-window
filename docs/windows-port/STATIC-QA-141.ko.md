# 공급자별 임계값 트레이 연결 정적 검토

140 구현 및 143 응답 슬롯 수정에 대해 141 최종 독립 정적 리뷰 APPROVE/CLEAR.

메뉴에서 정확한 공급자 ID로 설정을 로드하고 네이티브 편집창의 패치를 저장한다. 저장 실패는 같은 패치로 재시도하거나 취소한다. 요청 ID·공급자 ID·작업 종류가 일치하는 응답 하나만 잠금 아래 수락하며, 모달 진입 전에 기대 요청을 비워 중복 응답을 거부한다. 종료 시 응답 상태를 정리한다. 공급자 표시명은 비동기 작업 동안 유지한다.

세션 알림은 독립 전달한다. 임계값 알림만 편집·저장 동안 보류하며 저장 경계와 성공 응답에서 이전 알림을 비운다. 저장된 최신 설정 캐시 및 오래된 경고 평가 거부는 137 검토 범위다.

전체 기능 완료 판정이 아니다. 빌드·컴파일러·테스트·앱·Windows 실행 및 성능 측정은 하지 않았다. 네이티브 오버레이와 예측 알림 등은 별도 잔여 범위다.
