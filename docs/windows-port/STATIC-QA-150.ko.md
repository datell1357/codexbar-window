# 예측 경고 상태 전이 공용화 정적 검토

149 Core 추출과 151 원본 앱 위임 연결을 150이 재검토했다. 타입 별칭으로 기존 호출부 이름을 유지하고 상태 전이 함수는 공용 Core로 위임한다.

원본의 reset 시각 허용 범위(strict <), 같은 주기 보정, 계정/공급자/창 격리, 위험 최초 경고, 반복 억제, recovery 재무장, 낮은 확률에서 기존 상태 보존을 대조했다. TimeInterval 변환 뒤 분→초 곱셈으로 정수 overflow를 피하며 정상값과 음수의 기존 최소300초 처리는 유지한다.

정적 범위 승인. Windows 후보 산출·학습형 history·설정·전달은 미연결이며 예측 기능 완료로 집계하지 않는다. 빌드·테스트·컴파일러·실행 없음.
