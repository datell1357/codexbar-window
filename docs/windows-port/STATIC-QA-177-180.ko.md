# 이력 소유권·계정 스냅샷 정적 검토 177–180

제한된 추출/API 범위 APPROVE. 공유 소유권 resolver는 원본 canonical·이메일·plan utilization 해시와 계정 모호성 규칙을 보존한다. 일반 컨텍스트에서도 visible 계정의 동일 이메일 모호성을 항상 포함하도록 누락을 수정했다. visible 다중 계정 veto만 별도 모드로 제한하며 리뷰179에서 재확인했다.

CodexAccountContextSnapshot은 한 reconciliation snapshot에서 projection과 resolved source를 계산한다. 리뷰180에서 공개 타입과 기존 settings/visible 경로 의미를 확인했다. environment/home 및 Windows 런타임 전체가 동일 스냅샷을 재사용하도록 하는 후속 연결은 아직 미완료다.

빌드·테스트·컴파일·실계정 실행은 하지 않았다. Windows 레거시 이력 연결과 대시보드 역채우기 권한은 별도 미완료로 유지한다.
